# Document Style

When editing Markdown files (`.md`, `.markdown`), never hard-wrap prose:

- Write each paragraph as a single line, no matter how long it gets.
- Separate paragraphs and blocks with blank lines, never with a line break in the middle of a sentence.
- This applies to plain paragraphs, list items, and continuation lines of list items: keep the whole item on one line.
- The only places where newlines inside prose are allowed are Markdown structure: blank lines between blocks, list item markers, headings, and content inside fenced code blocks (which must keep their line breaks verbatim).

The editor soft-wraps long lines; do not insert hard line breaks that would survive in the file.
